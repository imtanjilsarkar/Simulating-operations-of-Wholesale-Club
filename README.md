---

##  Project Overview
**Simulating Operations of a Wholesale Club** is a Java-based OOP project that models the internal operations of a wholesale business.  
The system is designed using **role-based architecture**, where each role represents a real-world responsibility inside a wholesale club.

This project demonstrates how **Object-Oriented Programming concepts** can be applied to solve practical business problems in a structured and scalable way.

---

##  Project Objectives
- Apply **core OOP principles** in a real-world scenario  
- Design a **modular and maintainable system**
- Simulate **business operations digitally**
- Practice **team-based software development**

---

##  OOP Concepts Implemented
- **Encapsulation** – Data hiding using classes and access modifiers  
- **Inheritance** – Common behavior shared across roles  
- **Abstraction** – Clear separation of responsibilities  
- **Polymorphism** – Role-specific behavior implementation  
- **Modular Design** – Clean and reusable code structure

##  System User Roles

###  Cashier
- Handles customer billing
- Processes payments
- Maintains transaction records

###  Inventory Manager
- Monitors stock levels
- Updates inventory data
- Prevents stock shortages

###  Store Manager
- Oversees overall operations
- Reviews performance reports
- Makes operational decisions

###  Membership Manager
- Manages customer memberships
- Handles registration and renewal
- Maintains member benefits

###  Delivery Coordinator
- Schedules deliveries
- Tracks shipment status
- Coordinates logistics

###  Procurement Officer
- Purchases products from suppliers
- Manages supplier information
- Ensures cost efficiency

###  HR Manager
- Manages employee records
- Handles recruitment and attendance
- Oversees HR operations

###  Customer Support Staff
- Handles customer complaints
- Provides service assistance
- Ensures customer satisfaction
